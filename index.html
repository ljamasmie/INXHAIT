Requiere desplegar una vez el puente sheets_bridge.gs desde tu propia hoja (Extensiones → Apps Script). La hoja permanece privada; solo este endpoint, protegido por token, queda accesible.

Filtro de origen

Solo se muestran filas cuyo ID comienza con este prefijo (según la sección 2 del requerimiento).

Días hábiles

La "Fecha de entrega" se calcula como fecha de envío + N días hábiles completos (sin fraccionar por horas). El horario de jornada de arriba no afecta este cálculo — queda aquí solo por si más adelante quieres volver a un modo por horas.

Feriados — Ecuador

Estructura independiente de la fórmula de cálculo (sección 5). Incluye los feriados nacionales oficiales 2026 con traslados ya aplicados. Actualiza esta tabla cada año — no requiere tocar el código.

Nota técnica — conexión con Drive

Esta app lee la hoja vía el endpoint público gviz/tq de Google Sheets (solo lectura, sin API key), lo que cumple "actualización automática" sin backend. Limitaciones: (1) la hoja debe ser un Google Sheet nativo visible por enlace — un .xlsx sin convertir en Drive no es legible así; (2) si la información es sensible, este método no es privado. Para una fuente privada con OAuth, la arquitectura recomendada es Google Drive → Backend (Apps Script o servidor con Sheets API + service account) → este dashboard vía API propia, manteniendo igual el resto de los módulos (Transform, Calculator, Calendar, Dashboard).
